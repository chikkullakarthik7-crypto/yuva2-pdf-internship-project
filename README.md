# Yuva2 PDF Internship Project

A responsive browser-based PDF viewer created for an internship project.

## Features

- Upload a PDF file
- Preview it inside the browser
- Responsive interface
- No server-side upload required

## Run locally

Open `index.html` directly in a browser.
